What you can do in the app

Structured learning path

Follow a lesson map with quizzes, XP rewards, streaks, badges, challenges, and local certificates when you complete track goals.

Rich curriculum

Read bundled lesson content with headings, code samples, and figures—designed for small screens and offline use.

Playground & editor

Write HTML, CSS, and JavaScript in the playground with live preview. Save projects and use the mobile code editor workspace on device storage.

Open files on Android

Open or share HTML, CSS, JS, JSON, and XML from other apps into DevPath using standard Android intents—you choose which files to read.

Reminders

Optional local daily reminders (Android 13+ may request notification permission). No DevPath account is required.

Free with ads (release builds)

Release builds may show Google AdMob banner, interstitial, and rewarded ads. Debug builds use Google test ad IDs only.

Programming tracks

Filter lessons by track in the app. The catalog includes core web fundamentals plus extended tracks (counts from the shipped lesson catalog):

  • HTML
  • CSS
  • JavaScript
  • PHP
  • SQL
  • TypeScript
  • Python
  • Web Essentials
  • Capstone projects

PHP, SQL, and Python lessons teach concepts and syntax; the in-app playground runs HTML, CSS, and JavaScript only (no server-side execution in the app).
