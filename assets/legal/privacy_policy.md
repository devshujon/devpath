# DevPath Privacy Policy (in-app summary)

Effective date: 2026-10-14 · Last updated: 2026-10-19 · App version: 1.3.1 (build 16)

**Canonical web policy (Google Play / public URL):**  
https://solverpros.com/devpath/privacy-policy/

DevPath stores learning progress, XP, streaks, badges, saved projects, editor settings, and notification preferences locally on your device. There is no DevPath account or progress sync to DevPath servers in this version.

The app works primarily offline using bundled lessons and quizzes. Android declares INTERNET for AdMob (when ads load), libraries, and network-capable components.

**Advertising (release builds):** Production builds may show Google AdMob banner, interstitial, and rewarded ads using the production AdMob App ID in the release manifest. Debug builds use Google test AdMob IDs. AdMob and partners may process device/advertising data per Google’s policies. A User Messaging Platform (UMP) consent flow is not yet integrated in app code—see the web policy for regions that require consent.

The manifest declares AD_ID for ads. You can limit ad personalization in Android settings where available.

Notifications are scheduled locally if you grant POST_NOTIFICATIONS on Android 13+.

File import uses the system picker; only files you choose are read. DevPath does not upload your files or learning progress to DevPath servers in application code.

Android backup may copy app data per your device settings.

**Children:** Educational app with ads in release builds; not a dedicated under-13 product in code. Parents should supervise permissions and ads.

You may clear app data or uninstall to remove local information.

**Contact:** See the web privacy policy for support/email details before Play publication. Optional: GitHub issues on the DevPath repository if public.

For the complete policy, open the URL above in a browser or Profile → Privacy policy → Open in browser.
